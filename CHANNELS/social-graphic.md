# Social Graphic Channel

> Optional production reference. This file does not define a separate design language. Start with `../DESIGN.md`; use this only for crop, platform, and export details.

Use this channel for social posts, feed graphics, carousel slides, thumbnails, announcements, campaign tiles, and small-format promotional graphics.

Use this file after `DESIGN.md` when the task needs detailed crop, platform, or export guidance.

## Social Mindset

Social graphics need a fast first read and a strong crop. The work should still feel restrained, but it has less time and space to earn attention.

Avoid turning restraint into invisibility. A social graphic can be bold, but it should still use MCM's type, image, contrast, and negative-space logic.

## Format and Crop

Establish the format before designing:

- Square, portrait, landscape, story, thumbnail, or carousel
- Safe zones for platform UI
- Crop behavior in feed previews
- Whether the asset stands alone or belongs to a sequence

Keep the key subject, headline, and mark inside the safe area. Use edge tension deliberately, not by accident.

## Type

Use one clear first read. Large headlines can use tight negative tracking. Supporting text should be minimal, quiet, and normally tracked.

If the post needs more than one idea, use a carousel or sequence rather than compressing everything into one tile.

## Imagery

Use specific imagery: product state, studio artifact, documentary detail, material, person, place, or campaign subject. Avoid generic atmosphere.

Strong crops are appropriate when they increase recognition or intensity. Do not crop away the reason the image matters.

## Composition

Good social compositions:

- One strong image plus one sharp line.
- Large type with a compact non-linear orange signal. Never use an orange bar, rule, stripe, rail, divider, underline, or edge strip.
- Quiet metadata and strong edge alignment.
- Carousel rhythm that alternates statement, evidence, and detail.

Avoid:

- Multiple competing headlines.
- Icon decoration.
- Overloaded type blocks.
- Generic gradients or abstract vector backgrounds.

## Social Verification

Before finishing, check:

- The first read works at thumbnail size.
- The crop survives platform previews.
- Important text is inside the safe area.
- The graphic still feels MCM, not like a generic announcement template.
