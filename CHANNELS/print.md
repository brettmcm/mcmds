# Print Channel

Use this channel for printed collateral, PDFs intended for print, posters, one-sheets, brochures, leave-behinds, booklets, packaging concepts, and physical production.

Read `DESIGN.md` and `BRAND.md` first. This file translates those foundations into print work.

## Print Mindset

Print should feel tactile, deliberate, and edited. Let paper, scale, ink density, crop, and physical margins carry the system. Avoid translating web patterns directly into print.

## Format and Production

Establish the physical format before designing:

- Page size and orientation
- Bleed, trim, and safe area
- Binding, fold, or finishing constraints
- Single page, spread, booklet, or series
- Viewing distance
- Print method and color mode

Use production requirements from the printer, publisher, or vendor when available. If none are provided, assume the piece needs conservative bleed, safe margins, and high-resolution imagery.

## Color Translation

Start from the universal MCM palette, then translate for the production process. RGB values in `DESIGN.md` are design references, not final press values.

For print:

- Convert to CMYK or spot colors only when the output process requires it.
- Proof the warm paper and near-black values carefully; small color shifts can change the tone.
- Keep orange as an accent or signal, not a full-field theme.
- Use paper stock and ink coverage as part of the color system.

## Type in Print

Use the same hierarchy: display, headline, lead, body, label. Translate sizes into points based on format and viewing distance.

Guidance:

- Large cover or poster headlines can use tight negative tracking.
- Body copy should use normal tracking and comfortable leading.
- Captions, folios, notes, and production metadata should stay quiet.
- Do not make everything oversized just because the format is physical.

## Layout and Margins

Use a clear grid or margin system, then break it only for meaningful emphasis. Print has a physical edge, so margins and crops matter more than they do on flexible screens.

Good print moves:

- Full-bleed image when the image carries the subject.
- Wide margins when the content benefits from pause.
- Strong asymmetry when it creates pace across a spread.
- Thin rules for structure, not decoration.

Avoid:

- Web-card layouts copied onto a page.
- Dense decorative frames.
- Unnecessary icon sets.
- Text too close to trim or fold.

## Imagery

Use imagery at production-appropriate resolution. Crops should feel editorial and specific. Do not crop away meaning.

For personal, studio, or brand pieces, black-and-white or textured image treatment is appropriate when it improves focus and tone.

## Print Verification

Before finishing, check:

- Trim, bleed, and safe area are accounted for.
- Type is legible at final physical size.
- Image resolution is appropriate for output.
- Rich dark fields, warm paper tones, and orange accents will reproduce as intended.
- The first read is clear when viewed at the intended distance.
