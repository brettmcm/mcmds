# mcmds

MCMDS is minimal by subtraction. Begin with less than feels necessary.

`~/Projects/Scope` is the clearest reference: one quiet field, compact type, direct content, decisive contrast, and controls only when needed. Translate the restraint, not the interface.

## Use

1. Read `DESIGN.md`.
2. Read `BRAND.md` only for deeper creative or identity judgment.
3. Read `CREATIVE-DIRECTION.md` only when a technical or artifact-led atmosphere is explicitly useful.
4. Use a channel file only for a concrete production constraint.
5. Preserve host-project and accessibility requirements.

## Minimal default

- Cut the supplied text before designing.
- Show one idea, task, or decision at a time.
- Prefer one composition over a sequence of sections.
- Use one heading level whenever possible.
- Remove explanatory copy that repeats what the layout already communicates.
- Avoid labels, eyebrows, indices, captions, and metadata unless each one is necessary.
- Avoid divider lines. Use space, alignment, or tone instead.
- Avoid cards, panels, and decorative containers.
- Avoid showing multiple variants or states unless the user asks to compare them.
- Keep navigation and controls hidden or absent until needed.
- Use one accent, once.
- Never use orange as a bar, rule, stripe, rail, divider, underline, edge strip, or other linear accent in any channel. Use space, tone, alignment, type, imagery, or a compact non-linear semantic mark instead.
- Stop before the design feels filled.

For interfaces, start with a continuous field and direct objects. For static work, preserve the same quietness without importing product chrome.

Use sentence case. Use size as the last hierarchy lever. Reserve shadows for real floating layers.

## Dusty Times

Use the same minimal core with the official artwork in `assets/logos/`. Never redraw or decorate the logo.

## Check

- Can half the words go?
- Can most lines and containers go?
- Is every orange accent free of bar, rule, stripe, rail, divider, underline, and edge-strip treatment?
- Is there one unmistakable focal point?
- Is every remaining element necessary?
